# HIS AutoKey 11

Công cụ hỗ trợ nhập nhanh 6 thông số dấu hiệu sinh tồn (SpO2, Mạch, Nhiệt độ, HA Tâm thu, HA Tâm trương, Nhịp thở) vào phần mềm HIS bằng phím tắt Ctrl + B.

## Cách sử dụng
1. Tải HIS_AutoKey.exe từ mục [Releases](https://github.com/Tien360/his-autokey/releases/latest).
2. Mở file HIS_AutoKey.exe để chạy ngầm ở Khay hệ thống (System Tray).
3. Trên Web Sinh Hiệu bấm **Copy HIS**, sang HIS phủ khối ô SPO2 cũ và nhấn Ctrl + B.
